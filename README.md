# FinTrack — AI Powered Personal Finance Management App

FinTrack is a full-stack personal finance management application that helps users track expenses, manage budgets, monitor income, and gain AI-powered spending insights.

---

## Features

- JWT Authentication & Authorization
- Expense & Income Tracking
- Budget Management
- AI Spending Insights
- Analytics Dashboard
- Recurring Expense Automation
- Push Notifications
- PDF Financial Reports
- Dark Mode Support
- Responsive Flutter UI
- REST API Integration

---

## Tech Stack

### Frontend
- Flutter
- Dart
- Dio
- Provider
- SharedPreferences
- FL Chart

### Backend
- Spring Boot
- Spring Security
- JWT
- PostgreSQL
- Hibernate / JPA
